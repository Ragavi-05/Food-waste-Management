FoodWaste AI - AI-Powered Food Waste Tracker

An intelligent food waste management system designed for hotels, canteens, and food service establishments. Track, analyze, and predict food waste patterns to reduce costs and environmental impact.

## 🌟 Features

- **Dashboard Overview**: Real-time visualization of waste metrics and KPIs
- **Waste Data Logging**: Easy-to-use interface for recording daily food waste
- **Daily Logs**: Comprehensive history and tracking of all waste entries
- **AI Predictions**: Machine learning-powered forecasting for future waste patterns
- **Analytics**: Detailed analytics and reports to identify trends and opportunities
- **User Authentication**: Secure login and signup system
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies required

### Installation

1. Clone or download this project to your local machine
2. Open `index.html` in your web browser to access the landing page
3. Click "Get Started" or "Login" to access the main application

### Usage

1. **Sign Up**: Create a new account on the login page
2. **Access Dashboard**: View your waste management overview
3. **Log Waste Data**: Use "Add Waste Data" to record new entries
4. **Review Analytics**: Check daily logs and trends in the analytics section
5. **Get Predictions**: Use AI predictions to forecast future waste patterns
